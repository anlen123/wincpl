# 剪藏 v0.1.3

## 更新内容

- 修复开启代理/TUN/VPN 后二维码误选 `198.18.0.1` 等虚拟网卡地址的问题。使用 Windows 原生网卡信息，只选择已连接的物理 Wi-Fi/以太网私有 IPv4，优先有同子网网关的接口。
- 找不到可靠局域网地址时显示明确原因，不再生成虚拟网卡或回环地址的配对二维码。
- Android 新增完整短信诊断记录：收到短信广播、解析结果、关键词过滤原因、开始转发、接口返回或网络异常；新日志不记录短信正文、号码、验证码或配对令牌。
- 手机页面显示转发开关、接收短信权限、接收组件、通知和电池优化状态；最近 100 条记录自动刷新，并支持复制诊断日志。
- 短信权限与通知权限改为顺序请求；网络失败提示包含请求阶段、异常类型和耗时。
- 保留 v0.1.2 的托盘交互、标签切换、标签专用搜索及标签删除功能。
- 桌面端与 Android 统一升级至 0.1.3，Android versionCode=4，沿用原签名密钥。

## 下载与升级

- Windows x64 安装包：`jianzang-0.1.3-windows-x64-setup.exe`
- Windows 可执行文件：`jianzang.exe`
- Android APK：`jianzang-phone-0.1.3.apk`
- 校验文件：`SHA256SUMS.txt`

退出旧版电脑端后安装新版；手机覆盖安装 APK，再打开一次应用并确认短信权限和转发开关。电脑配对地址修正后，请手机重新扫码。手机与电脑仍需处于同一局域网。

如果短信到达后没有“收到短信广播”记录，请检查短信权限、自启动及后台省电限制；RCS/聊天应用消息不一定触发 SMS_RECEIVED。复制日志前请检查旧版遗留记录是否包含敏感内容。
